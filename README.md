# Zomato Food Ordering Website

A simple food ordering website inspired by Zomato, created using HTML, CSS and JavaScript.

## Features
- View food items
- Add items to cart
- Increase or decrease quantity
- Remove items
- Calculate total price
- Checkout page
- Order confirmation

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project.
2. Open `index.html` in your browser.
3. Add food items to your cart and try the checkout.

**Note:** This is a student project for learning purposes and is not the official Zomato website.
